ショートカット

「変更する」を押してから、使いたいキーの組み合わせを押すと登録します（Esc でやめる）。⌘（Windows は Ctrl）・Control・Option（Windows は Alt）のどれかを含めてください（F1〜F12 は単独でも可）。

音声入力（始める／止める）押すと聞き取りを始め、もう一度押すと止まります（入力欄のマイクボタンと同じ）。入力欄に文字を打っている最中でも効きます。オフィスの画面（執行役の入力欄）で使えます。

入力

入力の予測を出す執行役の返事が終わると、次に送りそうな短い返事（「OK」「A」「送って」など）を、入力欄に薄い文字で出します。Tab で入力欄に入ります（直してから送れます）。自動で送ることはありません。Esc で消せます。予測は軽いモデルで作ります（1回 1円未満・数秒）。

アシスタント

名前・執行役への追加の指示・部署を変えます。保存すると Claude の会話（この画面を出しているセッション）に届き、次の発言から使われます。ここで変えた内容は Claude Code の設定の置き場（プラグインの保存領域）に保存されます。

部署
部署は、執行役が Agent ツールで仕事を任せる相手です。名前は半角の英小文字・数字・ハイフンだけ（登録名になります）。消した部署は、いまの会話では登録が残りますが、執行役には出さなくなります（開き直すと完全に消えます）。部署の絵と色は、名前が同じなら引き継ぎます。
